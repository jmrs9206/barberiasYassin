# ADR-006: Next.js y Spring Boot

- **Estado:** aceptada

## Decisión

Next.js/React/TypeScript/Tailwind para frontend y Java/Spring Boot para API.

## Razones

- stack preferido;
- SEO público;
- ecosistema;
- separación clara;
- seguridad y dominio robustos.

## Reglas

- contrato OpenAPI;
- no duplicar reglas de negocio en frontend;
- versiones estables y soportadas;
- pruebas en ambos lados.
