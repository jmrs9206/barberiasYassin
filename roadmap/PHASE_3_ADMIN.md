# Fase 3: Panel de administración

## Objetivo

Que el dueño opere la barbería desde la interfaz.

## Tareas

- dashboard inicial;
- agenda;
- CRUD con archivo/restauración;
- citas manuales;
- cobro presencial;
- clientes;
- horarios;
- permisos;
- media;
- plantillas de correo;
- configuración de empresa;
- auditoría visible.

## Criterios

- responsive;
- accesible;
- no requiere SQL;
- permisos probados;
- cambios de precio no alteran citas.
