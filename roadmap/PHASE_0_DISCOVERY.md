# Fase 0: Descubrimiento y base documental

## Objetivo

Convertir el blueprint en un plan ejecutable sin escribir funcionalidad de negocio todavía.

## Tareas

- validar estructura del repositorio;
- elegir versiones soportadas;
- registrar ADR faltantes;
- crear backlog inicial;
- resolver contradicciones;
- definir comandos estándar;
- preparar `.gitignore`;
- preparar variables;
- documentar decisiones de auth y solapamiento;
- crear matriz de trazabilidad entre requisitos y fases.

## Entregables

- monorepo vacío coherente;
- README operativo;
- ADR revisados;
- backlog;
- checklist;
- riesgos;
- preguntas para el usuario;
- plan de Fase 1.

## Criterios

- no hay credenciales;
- el alcance MVP está congelado;
- versiones justificadas;
- no hay código de negocio prematuro;
- el usuario puede entender el plan.
