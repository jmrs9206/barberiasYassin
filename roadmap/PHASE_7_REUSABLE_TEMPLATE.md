# Fase 7: Plantilla multiempresa comercial

## Objetivo

Incorporar una segunda barbería sin duplicar código.

## Tareas

- onboarding;
- plan y límites;
- domains;
- módulos;
- exportación;
- suspensión;
- soporte;
- cuotas;
- personalización;
- documentación comercial;
- migración/importación.

## Prueba definitiva

Crear tenant B ficticio y demostrar aislamiento, branding, SMTP y configuración independiente.
