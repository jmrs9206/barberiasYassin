# Manifiesto del paquete

## Entradas para la IA

- `GEMINI.md`: reglas principales.
- `AGENTS.md`: contrato operativo.
- `MASTER_PROMPT_GEMINI.md`: prompt inicial.
- `CONTINUE_PROMPT.md`: prompt para continuar por fases.
- `.ai/`: flujo, roles, reglas y gates.
- `roadmap/`: orden de implementación.
- `contracts/`: contratos que no deben romperse.
- `adr/`: decisiones técnicas.
- `docs/`: especificación completa.
- `templates/`: plantillas de trabajo.

## Alcance del paquete

Este ZIP contiene especificaciones y workflow. No contiene una aplicación terminada ni credenciales reales. La cuenta inicial de superadministración debe crearse durante el despliegue mediante variables de entorno y rotación de contraseña.
