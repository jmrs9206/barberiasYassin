# Web pública

## Secciones configurables

- hero;
- llamada a reservar;
- servicios destacados;
- equipo;
- galería;
- sucursales;
- horarios;
- sobre nosotros;
- preguntas frecuentes;
- reseñas seleccionadas;
- contacto;
- redes;
- mapa;
- aviso temporal;
- footer legal.

## Contenido administrable

El dueño puede cambiar desde la interfaz:

- textos;
- imágenes;
- orden de secciones;
- visibilidad;
- colores dentro de un conjunto seguro;
- logotipo;
- favicon;
- meta title;
- meta description;
- Open Graph;
- enlaces sociales;
- información de contacto.

## SEO local

- datos estructurados cuando sean correctos;
- sitemap;
- robots;
- canonical;
- páginas de sucursal;
- URLs legibles;
- rendimiento;
- alt text;
- datos de nombre, dirección y teléfono consistentes.

No inventar teléfono ni información no entregada.

## Renderizado

Preferir SSR/SSG donde ayude a SEO. Los datos dinámicos de disponibilidad se obtienen desde API. No exponer secretos en frontend.
