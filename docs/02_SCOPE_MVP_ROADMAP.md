# Alcance del MVP y roadmap

## MVP obligatorio

### Web pública

- inicio;
- servicios;
- equipo;
- galería;
- sucursales;
- contacto;
- botón de reservar;
- textos legales;
- SEO local configurable.

### Reservas

- selección de sucursal;
- servicio;
- extra opcional;
- trabajador o cualquiera disponible;
- fecha y hora;
- datos del cliente;
- consentimiento;
- confirmación por correo;
- enlace seguro para consultar, cambiar o cancelar;
- reglas de cancelación;
- lista de espera básica opcional si entra en el plazo.

### Administración

- dashboard;
- agenda diaria/semanal;
- crear, editar, cancelar y completar citas;
- servicios, extras, precios y duraciones;
- trabajadores y horarios;
- sucursales;
- clientes;
- imágenes;
- plantillas de correo;
- informes básicos;
- configuración web;
- permisos.

### Superadministración

- empresas;
- sucursales;
- administradores;
- estado de tenant;
- uso de almacenamiento;
- errores de correo;
- auditoría;
- configuración de módulos;
- acceso de soporte auditado.

### Plataforma

- multiempresa;
- PostgreSQL;
- backups;
- almacenamiento local persistente;
- SMTP por empresa;
- seguridad;
- auditoría;
- RGPD por diseño;
- seed de Barbería Yassin.

## Fuera del MVP

- pagos online;
- TPV;
- facturación fiscal;
- contabilidad;
- nóminas;
- marketplace;
- SMS;
- automatización oficial de WhatsApp;
- aplicación móvil nativa;
- IA generativa para clientes;
- microservicios;
- inventario avanzado;
- programa de fidelización complejo;
- venta online de productos.

## Fases posteriores

- lista de espera automática avanzada;
- cupones y promociones;
- comisiones;
- inventario;
- reseñas internas;
- integración con calendarios;
- kiosco/recepción;
- MinIO;
- dominio automático;
- facturación si se define legalmente;
- analítica avanzada;
- importadores de terceros.
