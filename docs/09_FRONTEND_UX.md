# Frontend y experiencia de usuario

## Principios

- mobile first;
- interacción rápida;
- lenguaje claro;
- accesibilidad;
- diseño original;
- identidad configurable;
- no exigir contraseña para reservar;
- no ocultar costes;
- no generar falsas urgencias.

## Áreas

### Pública

- navegación simple;
- portada;
- servicios;
- equipo;
- galería;
- sucursales;
- reservas;
- contacto;
- legal.

### Cliente

- enlace seguro a próximas citas;
- modificar/cancelar;
- repetir reserva;
- actualizar datos;
- gestionar consentimientos.

### Administración

- dashboard;
- agenda;
- clientes;
- equipo;
- catálogo;
- media;
- web;
- informes;
- configuración.

### Superadministración

- empresas;
- soporte;
- salud operativa;
- auditoría;
- almacenamiento;
- correo;
- módulos.

## Componentes críticos

- selector de sucursal;
- selector de servicio;
- selector de trabajador;
- calendario de disponibilidad;
- resumen de cita;
- formulario de cliente;
- confirmación;
- agenda;
- modal de cita;
- tablas accesibles;
- filtros persistentes;
- subida de imágenes;
- cards de indicadores.

## Estados obligatorios

Cada vista debe contemplar:

- carga;
- vacío;
- error;
- permiso insuficiente;
- datos parciales;
- conflicto;
- éxito;
- reintento.

## Accesibilidad

- navegación por teclado;
- labels;
- contraste;
- foco visible;
- mensajes de error asociados;
- `aria-live` para cambios;
- no depender solo del color;
- alternativa textual para imágenes;
- calendario usable sin ratón.
